BIOS

INICIO

A la BIOS de mi ordenador Lenovo se accede según se está encendiendo el ordenador presionando repetidas veces la tecla F2.

 

Primero es la información de dicho ordenador en la que te viene el nombre del producto, la versión de la BIOS, la EC es el controlador embebido que es un microcontrolador que se encuentra alojado en las placas madres, este posee entradas y salidas e internamente posee características que son de suma necesidad. También tiene el número de MTM. El número de CPU, etc. También te viene la memoria del sistema, 0A3 Key ID es un código de 25 caracteres que se usa para activar Windows, Secure Boot protege el proceso de arranque contra ataques de seguridad de código malicioso como malware y ransomware.

 

 

 

 

En configuración:

Intel (R) Virtual Technology: permite que las máquinas virtuales controlen en su totalidad o en parte las asignaciones de unidades de procesos gráficos, además de motores aceleradores integrados en los productos que incluyen chips de Intel.

Intel (R) Hyper – Threading technology: sirve para duplicar la cantidad de hilos de ejecución de un procesador cualquiera.

BIOS back flash: Sirve para recuperar la BIOS de un error grave.

En seguridad:

Intel platforms trust technology: es una funcionalidad de plataforma para el almacenamiento de credenciales y la administración de claves que utilizan Windows 8 , Windows 10 y Windows 11.

Reset to setup mode: garantiza que el ordenador funcione con sus ajustes de fábrica.

Restore Factory Keys: Sirve para restaurar la configuración de fábrica.

En Boot:

USB mode: se refiere a una unidad extraíble de arranque que es capaz de iniciarse sola dentro del ordenador sin necesidad de un sistema operativo que abra las aplicaciones.

 

En Exit:

Load default settings, Os optimized defaults: ambas sirven para reconfigurarla con los valores por defectos.
